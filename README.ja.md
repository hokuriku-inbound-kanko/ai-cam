# ai-cam

福井駅で設置されたAIカメラによるインバウンド観光分析のための人口統計データを公開する、北陸インバウンド観光DXデータコンソーシアムが提供するデータセット。

## 背景
このリポジトリは、インバウンド観光パターンを分析するためのAI搭載カメラによって収集された人口統計データを提供します。福井駅は日本の北陸地方における重要な交通ハブであり、訪問者の性別、年齢、国籍、顔の向きを推定することで地域観光戦略の支援を行います。

## データファイル
データセットは単一のCSVファイルに保存されています。
- **`fukui_station.csv`**: AIの予測に対する信頼度スコアを含むタイムスタンプ付きの訪問者人口統計記録。各行は個々の検出を表し、性別、年齢、国籍分類、顔の向きなどの属性を持ちます。

## カラムリファレンス
| カラム          | 説明                                                                                                                                           | 値 / 範囲                          |
|------------------|------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------|
| `gender`         | 性別分類                                                                                                                                       | `1` = 男性, `0` = 女性             |
| `age`            | 個人の推定年齢                                                                                                                                 | 整数（例: 20, 65）                 |
| `accuracy`       | 性別と年齢予測の信頼度スコア                                                                                                                   | `0.000`–`1.000`                    |
| `nationality1`   | 国籍分類（日本人 vs 非日本人）                                                                                                                 | `1` = 日本人, `0` = 非日本人       |
| `accuracy`       | nationality1予測の信頼度スコア                                                                                                                 | `0.000`–`1.000`                    |
| `nationality2`   | 国籍分類（西洋 vs 非西洋）                                                                                                                     | `1` = 西洋, `0` = 非西洋           |
| `accuracy`       | nationality2予測の信頼度スコア                                                                                                                 | `0.000`–`1.000`                    |
| `nationality3`   | 国籍分類（西洋を除く非西洋 vs その他）                                                                                                         | `1` = 西洋を除く非西洋, `0` = その他 |
| `accuracy`       | nationality3予測の信頼度スコア                                                                                                                 | `0.000`–`1.000`                    |
| `direction`      | カメラに対する顔の向き                                                                                                                         | `0` = 前面, `0.5` = 背面, `1` = 全回転前面 |

## データ収集
データは**金沢大学が開発したAIカメラ**を用いて、**福井駅**に設置されたカメラによって収集されました。これらのカメラはリアルタイムの動画フィードを分析し、人口統計属性と顔の向きを推定し、訪問者の行動と人口統計に関する洞察を提供します。

## 公開者
このデータセットは**北陸インバウンド観光DXデータコンソーシアム**が公開しています。これは北陸地方のインバウンド観光をデータ駆動型戦略で強化するための共同イニシアチブです。
